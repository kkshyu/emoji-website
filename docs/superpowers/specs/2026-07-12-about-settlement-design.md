# 「關於聚落」獨立頁設計

日期：2026-07-12  
狀態：待使用者確認  
範圍：前台 `/about` 三語頁、導覽／頁尾連結、首頁移除 `#about`

## 目標

- 將創辦人對聚落的**想法、理念與背景**做成獨立頁「關於聚落」。
- 主軸是「為什麼做」：願景、四重動機、人才密度——不是營運手冊、不是會員銷售頁。
- 語氣為 **KK 第一人稱**（短段、直接、不硬推），並對齊公開 CIS「余白」；不做 LINE 式口語（哈哈／～／粗口）。
- 三語齊備（zh／en／ja）；導覽改連新頁；首頁 `#about` 整段移除以免重複。

## 非目標

- 不進 CMS／`site_content`（靜態 HTML 三語寫死）。
- 不把 fellow「關於 KK」整段搬過來；本頁僅短版＋連到 `/fellow`（或語系對應）。
- 不詳寫三條紅線、財務、法規、市場數據長表（留在計畫書／fellow）。
- 不重做 CIS 頁、空間頁、會員頁。
- 不做獨立後台編輯。

## 方法

**長文單欄＋極少錨點（做法 3-B）**：靜態宣言散文，保留 2–3 個安靜小標方便掃讀與深連結。

否決：區塊卡片牆（做法 1 變體）、CMS 可編（做法 2）、純無小標長文（做法 3-A）。

路由：`express.static(..., { extensions: ['html'] })` 已能讓 `/about` 直出 `about.html`，**不必**改 `server.js`（除非實作時發現語系路徑例外）。導覽 active 態可選加 `{{NAV_ABOUT_CURRENT}}`，對齊空間頁寫法。

## 前台頁面結構

單欄窄版（約 640–720px 內文寬），共用 site header／footer。

1. **Hero**  
   - Eyebrow：關於聚落／About／ハブについて  
   - H1：打造台灣人才密度最高的聚落（三語對應願景句）  
   - 一句副標：讓平常不會遇到的人，在台北車站旁相遇  
   - 黃強調色全頁至多一擊：建議落在 Hero 或文末 CTA 其一，不可兩處

2. **為什麼做**（`#why`）  
   - 安靜小標「為什麼做」  
   - 散文敘事，將四重動機**揉進文字**，不做成 01–04 卡片：  
     - 先做給自己與同類——自己不想天天待的地方就是失敗  
     - 台灣不缺人才，缺讓不同圈層彼此看見的場域  
     - 理念要生意養活；站前需求已在，做整合而非教育市場  
     - 把一棟樓做深，不是展店——深而不廣  
   - 收束：人才密度是靈魂；寧可短期少賺也要把空間留給對的人；丟了密度就只是又一間店

3. **我是誰**（`#kk`）  
   - 安靜小標「我是誰」  
   - 大頭照（沿用 `/fellow/kk.jpg` 或同等公開資產）＋姓名「徐愷 KK」  
   - 一段背景：工程師 → 創業／數位遊牧 → 把社群與網絡收斂成實體據點  
   - 現任角色 3–5 行（TDNA 理事長、Nomad Taiwan／相關公職表述以現有公開文案為準、言文字負責人等）  
   - 文內連結：完整故事 → 創始會員頁「關於 KK」（`/fellow#about` 或語系對應深連結）

4. **收束 CTA**  
   - 來看看空間 → `/space`（及語系）  
   - 一起開始 → `/fellow`（及語系）  
   - 無急迫推銷、無驚嘆號堆疊

錨點：`#why`、`#kk`（可選 `#cta`）。頁內不另做樓層式子導覽。

## 語氣（KK × CIS）

| 面向 | 要求 |
|------|------|
| 人稱 | 第一人稱「我」；英文用 I；日文用私 |
| 節奏 | 短段、換行斷句；可掃讀；避免公文腔與行銷最高級 |
| KK | 直接講為什麼、使命感真實、效率／密度優先；可帶一點乾淨的自嘲，但克制 |
| 禁用（本頁） | LINE 語助（哈哈、～、乾）、emoji 堆疊、驚嘆號推銷 |
| CIS | 余白、質感、不急銷售；母品牌「言文字｜台灣人才聚落」；分隔符全形 `｜` |
| 法遵 | 本頁不描述二樓休憩產品細節；若提及空間，沿用既有公開用詞、禁用住宿／旅館等詞 |

文案素材優先來源：`營運計畫書_母檔.md` §2.1–2.2、§2.5；fellow「關於 KK」公開段落作短版濃縮——**不**引用人格規格檔中的 ≈／◇ 例句當「KK 說過的話」。

## CIS 視覺

| 面向 | 要求 |
|------|------|
| 色彩 | 墨 `#1B1A17`、紙白灰階；黃 `#FFDE34` 每畫面至多一擊、只當底、墨字壓上 |
| 字體 | 標題 Noto Serif TC；拉丁／數字 Cormorant Garamond；內文 Noto Sans TC |
| 版面 | 大余白；不堆卡片牆；無紫光、無多層陰影裝飾 |
| 動效 | 進場淡入 2–3 處；尊重 `prefers-reduced-motion` |
| Hero | 品牌／願景為主；不放統計條、樓層卡、促銷貼紙、浮動 badge |
| 檢核 | 完成前跑 CIS 三秒檢核：焦點、留白、黃只一擊、手機仍有余白 |

頁面專用 CSS：`public/about.css`（三語共用）；沿用 `/style.css`、`/nav.css` token，不另開色票。
