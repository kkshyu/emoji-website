# IG 貼文產生器（後台）設計

日期：2026-07-12　分支：`ig-template-admin`

## 目標
讓管理員在後台 `admin.html` 填入資訊/照片，即時預覽並下載可直接發布的 IG 貼文圖片（PNG），可選方形（1080×1080）或直式（1080×1350）。

## 範圍
- 後台新增「IG 貼文」分頁，沿用現有 Google 管理員登入（`role==='admin'` 才顯示）。
- 純前端產圖：**不新增後端 API、不動 `server.js`、不動資料庫**。

## 型別（3 種 × 2 比例）
沿用現有 IG 模板 CIS 版面語言（墨/紙/唯一黃 #FFDE34、明體標題、螢光筆底線、顯示英文可切）。
1. **單品／價目** — 照片＋中英品名＋敘述＋原價/會員價。
2. **活動預告** — 標題＋時間＋地點＋敘述＋照片。
3. **金句／字** — 大字＋副題（純文字）。

每型皆有直式 1080×1350 與方形 1080×1080 兩種版型。

## 菜單資料帶入
`public/menu-data.js` 內建 legacy menu 4 分類（COFFEE / BEVERAGE / ALCOHOL / FOOD）全部品項與雙價（原價 / EMO 會員價）。單品型別可下拉選品項自動填欄位，仍可手改。舊產品照非 CIS 風格，不內建；照片由管理員上傳。

## UI
左填右看：左欄表單（型別 → 方形/直式 → 欄位 → 照片上傳 → 明底/暗底、顯示英文、顯示會員價開關）；右欄即時預覽（真實 1080 尺寸以 CSS `transform: scale()` 縮小塞入面板，輸入即時更新）。

## 匯出
純前端，vendored `html-to-image`（單檔置 `public/vendor/`，不進 npm、不需 build）。擷取離屏原尺寸節點轉 PNG 下載，檔名如 `言文字_IG_單品_美式咖啡.png`。
- 擷取前 `await document.fonts.ready`，確保明體 web font（Noto Serif TC）內嵌完整 —— 首要驗證點。
- 上傳照片以 dataURL 內嵌（同源，canvas 不會被污染）。

## 檔案異動
- 新增 `public/ig-studio.js`（表單＋預覽＋模板＋匯出邏輯）
- 新增 `public/menu-data.js`（菜單資料）
- 新增 `public/vendor/html-to-image.js`（vendored 函式庫）
- 修改 `public/admin.html`：載入 script、TABS 加一項、bind() 掛載（約三行）

## 驗收
1. 後台以管理員登入可見「IG 貼文」分頁。
2. 選單品型別、下拉選「美式咖啡」→ 欄位自動帶入品名/雙價。
3. 切換方形/直式，預覽即時改變比例與版面。
4. 上傳照片後預覽顯示照片。
5. 按下載得到對應比例的 PNG，明體標題字型正確、螢光筆與唯一黃呈現正確。
