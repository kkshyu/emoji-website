# 計畫文案對齊營運計畫書 — 設計 Spec

**日期**：2026-07-12  
**範圍決策**：A（三計畫頁＋首頁對應區塊）／內容對齊（非語氣重寫）／zh・en・ja 三語  
**做法**：嚴格對齊《營運計畫書_母檔》（做法 A）  
**事實來源**：《營運計畫書_母檔.md》第六章（§6.1／§6.3／§6.5）為準

## 目標

讓網站上 **fellow／partner／startup** 三計畫頁與首頁 `#founding`／`#partners`／`#startup`（含相關 FAQ／JSON-LD）的對外承諾，只陳述計畫書已定案事實；探索項目不得寫成可報名產品。

## 非目標

- 不改會員單日／月／季／年方案頁與點數價目主說明（屬另一產品面）。
- 不改 `fellow/app.js` 協議全文與購買後端（除非權益句與計畫書直接衝突且無法只靠 HTML 校正——本輪預設不動協議）。
- 不重構版型 CSS（`founding.css`／`partner.css`／`startup.css` 骨架可沿用，只換文案與區塊標題）。
- 不做 KK 語氣重寫；維持 CIS：短句、少形容詞、無驚嘆號、無推銷腔。

## 設計原則

1. **未定案不超賣**：§6.5 探索項目、未核准價格／名額，一律標探索／意向／以公告或合約為準。
2. **數字以計畫書為準**：創始會員條件以 §6.1 為 SoT。
3. **中文定稿 → en／ja 對譯**：三語事實一致，不各寫各的產品故事。
4. **聯絡一致**：三計畫頁＋首頁 CTA 信箱統一為一支（實作時以站內多數為準，避免混用）。

## ① fellow — 創始會員（§6.1）

### 現況判斷

核心條件已大致正確；本輪以**補漏＋統一表述**為主。

### 維持

| 項目 | 值 |
|------|-----|
| 會費 | NT$35,000（與年費同牌價，加量不打折） |
| 會籍 | 18 個月；目標起迄 2026-11-01 → 2028-04-30 |
| 贈點 | 2,000（一年效期） |
| 名額 | 限量 100；售至 2026-10-31；售罄不補 |
| 創始專屬 | 三樓創始牆、創始晚餐、續約鎖價 |
| 開幕延後 | 自實際開幕日起算，期間與贈點不縮減 |
| 二樓 | 條件式（法遵 Gate 通過前依規章） |

### 要改

1. **首屏條款卡**：贈點列加「一年效期」；加「不可退費，僅可轉讓」。
2. **會員權益頁**：明寫＝年會員權益延長為 18 個月＋贈點 2,000；設施＝三樓自由使用＋社群／互助；二樓淋浴 7 點／次、膠囊／娛樂室 10 點／小時（須 Active／Gate）；刪「以額度折抵」等舊表述。
3. **誠實須知**：統一不可退費僅可轉讓；會員規章律師核定（目標 2026/09/15 前）；二樓用語對齊 Gate。
4. **首頁 `#founding`＋FAQ／schema**：同步上列。
5. **en／ja**：事實對譯。

### 不改

購買流程、名額進度條、版型 CSS、協議全文。About／Why now 僅事實校正，不做語氣重寫。

## ② partner — 社群夥伴／活動合作（§6.3）

### 現況判斷

網站自造 Event Salon／Event Partner／Event Circle 產品線，計畫書無此三分法。

### 拿掉

- Event Salon／Event Partner／Event Circle 名稱與「三種合作方式」主脊產品敘事。

### 改成

| 區塊 | 內容 |
|------|------|
| 命名／Hero | 活動／場地／社群合作說明；個案討論、書面協議 |
| 合作形態 | Talent Night、媒合晚餐、TDNA 系列、講座／工作坊、家教／教學、外部包場 |
| 家教 | 老師免費使用空間、學生付計時費 |
| 包場 | 可承接；不得排擠核心社群時段；禁止直銷、投資詐騙、宗教及政治動員 |
| TDNA Event Partner | 場地費支持原規劃 25–100%，**實際比例以書面合作協議為準** |
| 為什麼是言文字 | 保留位置／社群／TDNA／三樓；刪過度承諾 |
| 誠實須知 | 個案、合約為準、明帳互惠、禁止事項 |
| 首頁 `#partners` | 改為上表形態；CTA「聊聊合作」 |

版型骨架可沿用；不新造定價、不開放線上結帳。en／ja 同步。

## ③ startup — 新創支援・探索（§6.5）

### 現況判斷

網站寫成固定三、六、九月梯次＋完整陪跑產品；計畫書定位為**探索項目，不入財務基準**。

### 拿掉

- 每年三、六、九月固定召募  
- Apply → Talk → Select → Run 產品流程  
- 「陪你跑完」「三大支援」保證式敘事  
- 任何「已開放報名梯次」語氣（含 meta／FAQ／schema）

### 改成

| 區塊 | 內容 |
|------|------|
| 命名 | 新創支援（探索）；en：Startup Support (Exploratory) |
| Hero | 雙向橋可留；標明探索中、非已定產品 |
| 可能形態 | 登記地址 → 新創方案（登記＋固定席位＋會議室額度）→ 媒合資源（TDNA、CaseCake） |
| 決策門檻 | 開幕 **3 個月後**依會員結構評估；登記地址之法務／稅務先經會計師確認 |
| 財務邊界 | **不列入財務基準與貸款還款來源**（誠實須知必寫） |
| CTA | 「登記意向／聊聊」；不承諾梯次、名額、入選 |
| 背景錨點 | 簽證紅利、TDNA、Fest、站前據點＝生態系背景，非「已含在陪跑方案」 |
| 首頁 `#startup` | 與上列同步 |

版型 CSS 不重構；不接報名後端；不寫定價。en／ja 同步。
